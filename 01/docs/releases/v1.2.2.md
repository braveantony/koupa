# Koupa v1.2.2 / v2.2.2

發布日期：2026-11-11

修正：叫號看板 `?debug=1` 資訊列的 Pod，現在會跟著 SSE 連線更新，重連到別的 Pod 後顯示的就是新的那一個。

## Summary of Changes

**Minor Changes:**
* 看板 SSE 連線一開始的 `hello` 事件多了 `pod_name`、`pod_uid`（欄位名稱同 `/api/whoami`），原本的 `version` 不變 (PR braveantony/koupa#15, @braveantony)

**Bugfixes:**
* 看板 debug 列的 Pod 改從每次的 `hello` 事件取得：rolling update 期間 SSE 斷線、重連到另一個 Pod 時，不再停在網頁載入時查到的舊 Pod (PR braveantony/koupa#15, @braveantony)

**Misc Changes:**
* 新增 release notes（`01/docs/releases/`），發布新版時一起寫 (PR braveantony/koupa#15, @braveantony)

## 升級方式

`git pull` 後重跑 `./setup.sh`。tag 換了新的版本號，Kubernetes 會照平常的 rolling update 拉新映像檔，不需要在節點上 `crictl pull`。
